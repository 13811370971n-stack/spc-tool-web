# SPC Tool Web 用户手册

## 简介

SPC Tool Web 是一款基于浏览器的统计过程控制工具，支持 9 种控制图、过程能力分析和正态性检验。无需安装桌面软件，打开浏览器即可使用。

## 通用操作流程

所有分析页面遵循相同的 3 步操作：

### 第 1 步：上传数据

1. 点击 **"上传 CSV/Excel"** 按钮
2. 选择 `.csv`、`.xls` 或 `.xlsx` 文件
3. 上传成功后显示文件名和行列数
4. 数据预览表格自动出现（前 5 行）

**支持的数据格式：**
- CSV（逗号分隔，UTF-8 编码）
- Excel 97-2003（.xls）
- Excel 2007+（.xlsx）

### 第 2 步：选择列和参数

根据不同图表类型选择相应的列：

| 图表类型 | 需要选择的列 |
|----------|-------------|
| Xbar-R / Xbar-S | 多选测量值列（每列=子组内一个样品） |
| I-MR / EWMA | 单选数值列 |
| P / U Chart | 不合格品/缺陷数列 + 样本量列 |
| NP Chart | 不合格品数列 + 输入常数样本量 |
| C Chart | 缺陷数列 |
| Z-MR | 测量值列 + 零件类型列 |
| 过程能力 | 数据列 + **USL/LSL（必填）** |

**可选参数：**
- USL / LSL：规格上限/下限（过程能力计算需要）
- 判异规则：Test 1~8 可勾选（默认启用 1~4）
- EWMA 参数：λ（平滑系数）、L（限宽系数）
- 数据变换：Box-Cox / Johnson（过程能力页面）

### 第 3 步：点击分析

点击 **"▶ 分析"** 按钮，生成：
- 📊 交互式控制图（Plotly）
- 📋 结果统计表
- 📝 判异解读文本

## 判异规则说明

工具支持 AIAG SPC 标准的 8 条 Western Electric 判异规则：

| 规则 | 描述 | 默认 |
|------|------|------|
| Test 1 | 1 点超出 3σ 控制限 | ✅ 启用 |
| Test 2 | 连续 9 点在中心线同侧 | ✅ 启用 |
| Test 3 | 连续 6 点递增或递减 | ✅ 启用 |
| Test 4 | 连续 14 点交替升降 | ✅ 启用 |
| Test 5 | 3 点中 2 点超过 2σ（同侧） | 未启用 |
| Test 6 | 5 点中 4 点超过 1σ（同侧） | 未启用 |
| Test 7 | 连续 15 点在 1σ 内（层化） | 未启用 |
| Test 8 | 连续 8 点在 1σ 外（混料） | 未启用 |

失控点在图表中以红色空心圆标注，解读文本给出可能的物理原因。

## 各页面详细说明

### Xbar-R 控制图

**适用场景：** 子组大小 2~10 的计量型数据

**数据格式（宽格式）：**
| 直径1 | 直径2 | 直径3 | 直径4 | 直径5 |
|--------|--------|--------|--------|--------|
| 10.948 | 10.903 | 10.947 | 10.962 | 10.984 |
| 10.913 | 10.969 | 10.949 | 10.980 | 10.939 |

**操作：**
1. 上传文件
2. 在 "测量值列" 下拉框中多选所有测量列（如 直径1~5）
3. 可选：指定子组列、填写 USL/LSL
4. 勾选判异规则
5. 点击分析

**输出解读：**
- Xbar 均值图：监控过程中心是否偏移
- R 极差图：监控过程变异是否稳定
- σ_within vs σ_overall：判断组间变异来源

---

### I-MR 控制图

**适用场景：** 每次只测量一个值（n=1），如连续化工过程、破坏性检验

**数据格式：**
| 天 | 尾气浓度 |
|----|---------|
| 1  | 58.2    |
| 2  | 60.1    |
| 3  | 57.8    |

**操作：**
1. 上传文件
2. 选择数据列（如 "尾气浓度"）
3. 点击分析

---

### P 控制图

**适用场景：** 不合格品率监控（样本量可变）

**数据格式：**
| 日期 | 样品数量 | 不合格品数量 |
|------|---------|-------------|
| 6/1  | 150     | 3           |
| 6/2  | 120     | 5           |

**操作：**
1. 上传文件
2. 不合格品数列 → 选 "不合格品数量"
3. 样本量列 → 选 "样品数量"
4. 点击分析

**注意：** 样本量不等时，控制限为变动曲线（而非水平线）。

---

### 过程能力分析

**适用场景：** 评估过程满足规格要求的能力

**必填：** 至少一个规格限（USL 或 LSL）

**操作：**
1. 上传文件，选择数据列
2. 填写 USL 和 LSL（**必填**）
3. 可选：Target（目标值）、子组大小
4. 如数据非正态：选择 Box-Cox 或 Johnson 变换
5. 点击分析

**输出指标：**
| 指标 | 含义 | 判定标准 |
|------|------|---------|
| Cp | 潜在能力（不考虑偏移） | ≥1.33 良好 |
| Cpk | 实际能力（考虑偏移） | ≥1.33 良好，≥1.67 优秀 |
| Pp | 整体能力（长期） | — |
| Ppk | 整体实际能力 | — |
| PPM | 预期百万分之不良率 | 越小越好 |

---

### 正态性检验

**适用场景：** 判断数据是否服从正态分布（能力分析的前提）

**输出：**
- Q-Q 概率图（数据点应贴近红线）
- 直方图 + 正态拟合曲线
- Box-Cox λ 优化曲线
- 三种检验结果（AD / SW / KS）

**判定：** 3 个检验中 ≥2 个通过 → 正态

## AI 增强解读

分析完成后，点击 **"🤖 AI 增强解读"** 按钮：

- 调用大语言模型（LLM）给出深层分析
- 包括：根因假设、物理原因解释、改进建议（短/中/长期）
- 支持多种后端（OpenAI / Ollama / DeepSeek）

### AI 配置

配置文件位置：`~/.spc-tool/llm_config.json`

```json
{
  "enabled": true,
  "backend": "ollama",
  "model": "qwen3:8b",
  "base_url": "http://localhost:11434/v1",
  "temperature": 0.3,
  "max_tokens": 2000
}
```

| 后端 | base_url | 说明 |
|------|----------|------|
| ollama | http://localhost:11434/v1 | 本地免费 |
| openai | （留空） | 需 api_key |
| deepseek | https://api.deepseek.com | 需 api_key |

## 常见问题

### Q: 上传文件后看不到列？
检查文件是否为有效的 CSV/Excel 格式。中文列名正常支持。

### Q: Xbar-R 分析结果和 Minitab 不一致？
确认选对了列。文件中可能有"长格式"原始列和"宽格式"子组列混在一起，只选宽格式的测量列（如 直径1~5）。

### Q: P 图的控制限为什么是曲线？
当各子组样本量不等时，控制限随 n 变化。这是正确行为。

### Q: 过程能力分析报错？
必须至少填写一个规格限（USL 或 LSL）。

### Q: AI 按钮无响应？
检查 `~/.spc-tool/llm_config.json` 是否配置正确，`enabled` 是否为 `true`。
